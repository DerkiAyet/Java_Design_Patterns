# Java Design Patterns

Implementations of the classic **Gang of Four design patterns** in Java, with simple, runnable examples. Built while studying object-oriented design.

## 🚀 Running an example

Each file is self-contained and has a `main` method.

```bash
javac structural/AdapterPattern.java
java structural.AdapterPattern
```

## 🎯 Purpose

A personal reference to understand when and why each pattern is used, with minimal code and no framework dependencies.
